# Plano de Deploy

## Opções recomendadas

1. Vercel
   - Simples para site React/Next/Vite.
   - Bom para portfólio público.

2. Netlify
   - Simples para site estático.
   - Bom para formulários simples.

3. GitHub Pages
   - Bom para site estático simples.
   - Menos flexível que Vercel/Netlify.

## Antes do deploy

- Rodar checklist de publicação.
- Validar dados sensíveis.
- Otimizar assets.
- Gerar build local.
- Conferir mobile.

## Pós-deploy

- Testar URL pública.
- Conferir metadados sociais.
- Abrir em janela anônima.
- Verificar que nenhum asset privado está sendo servido.
