# Checklist de Publicação

## Conteúdo

- [ ] Hero claro e específico.
- [ ] Cases visíveis na home.
- [ ] Cada case tem problema, solução, stack e evidência.
- [ ] Não há métricas inventadas.
- [ ] Não há linguagem exagerada.

## Segurança

- [ ] Nenhum dado real de cliente/família.
- [ ] Nenhum CPF/CNPJ real.
- [ ] Nenhum telefone/e-mail real.
- [ ] Nenhum ID de Drive/Sheets/Calendar/Tasks.
- [ ] Nenhuma credencial.
- [ ] Nenhum JSON bruto não sanitizado.

## Visual

- [ ] Layout responsivo.
- [ ] Imagens legíveis.
- [ ] Vídeos curtos e otimizados.
- [ ] Textos com contraste.
- [ ] CTA visível.

## Técnico

- [ ] Build local funcionando.
- [ ] Sem erros no console.
- [ ] Links externos revisados.
- [ ] Meta title e description.
- [ ] Open Graph básico.

## Publicação

- [ ] Revisão final feita.
- [ ] Deploy autorizado.
- [ ] URL testada.
- [ ] Site conferido em mobile.
