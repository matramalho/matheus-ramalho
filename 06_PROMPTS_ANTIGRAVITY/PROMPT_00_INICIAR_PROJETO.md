Criar um site institucional/portfólio profissional para apresentar cases de automação com n8n, IA aplicada, Google Workspace e agentes/workflows documentados.

6. Leia `04_DESIGN_SYSTEM/DESIGN_SYSTEM_GUIDE.md`.

Regras:
- Não usar dados reais.
- Não publicar JSON bruto.
- Não expor IDs de Google Drive, Sheets, Calendar ou Tasks.
- Não usar credenciais.
- Não apagar arquivos.
- Não mexer em workflows n8n sem autorização.
- Não usar terminal sem autorização.
- Não acessar navegador sem autorização.
