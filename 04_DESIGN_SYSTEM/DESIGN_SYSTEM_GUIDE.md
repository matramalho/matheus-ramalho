# Design System Guide — Portfolio Automação IA

## Personalidade visual

- Sóbrio.
- Técnico.
- Premium acessível.
- Baseado em evidências reais.
- Sem estética genérica de “robô IA”.

## Paleta sugerida

```text
Background dark: #0B1020
Surface:         #111827
Surface soft:    #1F2937
Text primary:    #F9FAFB
Text secondary:  #CBD5E1
Blue accent:     #38BDF8
Purple accent:   #A78BFA
Green accent:    #34D399
Amber accent:    #F59E0B
Border:          #334155
```

## Tipografia

- Títulos: Inter, Sora, Manrope ou similar.
- Corpo: Inter, system-ui ou similar.
- Código/badges: JetBrains Mono ou similar.

## Componentes

### Case Card

- Título.
- Descrição de 2 linhas.
- Stack badges.
- Miniatura do workflow.
- CTA: “Ver case”.

### Evidence Block

- Print grande.
- Legenda curta.
- Lista de pontos observáveis.

### Process Timeline

1. Mapear.
2. Automatizar.
3. Testar.
4. Documentar.
5. Evoluir.

### Stack Badge

Pílulas pequenas com nome da ferramenta.

## Motion

- Microanimações leves.
- Hover em cards.
- Fade-in sutil.
- Evitar parallax pesado ou canvas 3D desnecessário.
