# Guardrails de Segurança — Portfólio Público

## Regras absolutas

- Não publicar documentos reais.
- Não publicar JSON bruto com IDs reais de Google Drive, Sheets, Calendar ou Tasks.
- Não publicar credenciais, tokens, e-mails privados, CPFs, CNPJs, telefones ou nomes reais de clientes.
- Não publicar links privados do Google Drive.
- Não publicar prints com barra de endereço expondo IDs sensíveis.
- Não usar dados reais em vídeos de demonstração.
- Não deixar abas pessoais, e-mail, WhatsApp Web, bookmarks ou notificações aparecendo em gravações.

## Antes de publicar print ou vídeo

Verificar se aparecem:

- nome real de cliente;
- CPF/CNPJ;
- telefone;
- e-mail;
- placa real;
- apólice real;
- ID de documento/planilha/pasta;
- conta Google;
- credenciais n8n;
- dados familiares ou pessoais.

## Regra para JSON

JSON de workflow só pode ser publicado se for uma versão sanitizada com:

- IDs substituídos por placeholders;
- credenciais removidas/substituídas;
- URLs privadas removidas;
- dados de teste fictícios;
- aviso claro: “versão sanitizada para portfólio, não importar em produção”.

## Frases seguras

- “protótipo funcional com dados fictícios”;
- “case demonstrativo baseado em cenário operacional realista”;
- “workflow preparado para reduzir trabalho manual e aumentar rastreabilidade”;
- “resultados esperados, não métricas auditadas”.

## Frases a evitar

- “100% automático sem falhas”;
- “garantia de redução de custos”;
- “sem necessidade de supervisão”;
- “dados reais processados em produção”;
- “ROI comprovado” sem medição.
