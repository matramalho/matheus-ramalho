# Skill 06 — Frontend Implementation

## Objetivo

Orientar a implementação do site institucional no Antigravity com código limpo, responsivo e fácil de manter.

## Requisitos técnicos sugeridos

- Site estático ou SPA simples.
- Componentização clara.
- Responsividade mobile-first.
- Performance alta.
- SEO básico.
- Acessibilidade básica.

## Boas práticas

- Separar conteúdo em arquivos de dados quando possível.
- Manter assets organizados.
- Criar componentes reutilizáveis para cards e cases.
- Evitar dependências desnecessárias.
- Usar vídeos otimizados.

## Checklist

- [ ] Hero aparece corretamente no mobile.
- [ ] Cards não quebram.
- [ ] Vídeos têm fallback/thumbnail.
- [ ] Alt text em imagens.
- [ ] Links externos abrem corretamente.
- [ ] Não há dados sensíveis no bundle final.
