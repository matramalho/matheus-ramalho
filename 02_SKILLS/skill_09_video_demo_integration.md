# Skill 09 — Integração de Vídeos e Evidências

## Objetivo

Preparar vídeos curtos de demonstração para uso no site.

## Diretrizes

- Vídeos de 30 a 90 segundos.
- Sem narração obrigatória.
- Texto sobreposto explicando as etapas.
- Dados fictícios.
- Foco em antes → execução → resultado.

## Estrutura de vídeo

1. Pasta/planilha antes.
2. Workflow no n8n.
3. Execução.
4. Resultado no Sheets/Drive.
5. Blueprint final.

## Regras

- Não mostrar PDF real.
- Não mostrar IDs ou URLs privadas.
- Não mostrar credenciais.
- Se necessário, usar blur ou recorte.
