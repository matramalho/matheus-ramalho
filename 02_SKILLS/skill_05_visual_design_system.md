# Skill 05 — Design System Visual

## Objetivo

Criar uma identidade visual premium, limpa e técnica para o portfólio.

## Direção visual

- Base escura ou off-white.
- Cards com bordas suaves.
- Acentos em azul, roxo, verde e âmbar.
- Tipografia legível.
- Visual de “arquitetura operacional”, não “template genérico”.

## Componentes

- Hero com headline e subtítulo.
- Bento grid de capacidades.
- Cards de case.
- Timeline de processo.
- Galeria de prints/vídeos.
- Badges de stack.
- CTA final.

## Regras

- Não poluir com animações pesadas.
- Não deixar print pequeno demais.
- Não usar imagem gerada genérica de robô/IA.
- Preferir evidências reais do projeto.
