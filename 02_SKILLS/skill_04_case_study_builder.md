# Skill 04 — Case Study Builder

## Objetivo

Transformar cada workflow em um case claro, com narrativa de problema, solução, arquitetura e evidência.

## Template de case

1. Título.
2. Resumo em 3 linhas.
3. Problema operacional.
4. Solução criada.
5. Como funciona.
6. Stack.
7. Regras de negócio.
8. Evidências.
9. Resultado esperado.
10. Cuidados de segurança.
11. Melhorias futuras.

## Regras

- Não inventar métricas.
- Não usar dados reais.
- Sempre indicar se os dados são fictícios.
- Usar prints e vídeos como prova visual.
- Explicar o valor de negócio antes do detalhe técnico.
