# Skill 10 — Operação Segura no Antigravity

## Objetivo

Orientar agentes no Antigravity para trabalhar no site sem comprometer dados sensíveis.

## Regras

- Não apagar arquivos sem listar antes.
- Não mexer em workflows n8n funcionais sem autorização.
- Não abrir arquivos com credenciais.
- Não executar scripts destrutivos.
- Não usar navegador para contas pessoais sem autorização.
- Não publicar assets sem revisão LGPD.

## Fluxo de trabalho

1. Ler `PROJECT_BRIEF.md`.
2. Ler skills relevantes.
3. Criar plano antes de editar.
4. Editar arquivos em pequenos lotes.
5. Rodar verificação local se permitido.
6. Registrar alterações no changelog.
7. Solicitar revisão humana.
